# Aventura en Inglés

Juego web interactivo para practicar inglés (partes de la cara, adjetivos, has/have, is/isn't, ordenar oraciones). Un solo archivo estático, sin dependencias ni build.

## Subir a GitHub
1. Crea un repositorio nuevo en GitHub.
2. Sube estos archivos a la raíz: `index.html`, `vercel.json`, `.gitignore`, `README.md`.

## Deploy en Vercel
1. En Vercel: Add New > Project > importa el repositorio.
2. Framework Preset: **Other**. Deja vacíos Build Command y Output Directory.
3. Deploy.

Cada cambio que subas a GitHub se publica solo.
